# 古體詩：脫離管絃的文人士大夫長篇言情

## 一、文體界定與起源
- **名稱由來**：又稱「古體詩」、「古風」，是相對於唐代形成的「近體詩（今體詩）」而言。
- **誕生時代**：產生於兩漢，由樂府詩演變而來。漢末五言古詩正式成型，東漢班固〈詠史詩〉為現存最早文人署名的成熟五言詩；《古詩十九首》則標誌著五言古詩在藝術上的極致成熟。
- **與樂府詩的分野**：樂府「入樂可歌、多民間作、多雜言長短句、主敘事」；古體詩則「不入樂（徒誦不歌）、多士大夫文人作、句式較嚴整（多五言、七言）、主言情溫雅」。二者並稱漢代詩歌文學雙葩。

## 二、句式、格律與體製特徵
| 特徵面向 | 古體詩規格 |
| :--- | :--- |
| **句式規格** | 以五言、七言為主流，亦有雜言；三國曹丕〈燕歌行〉為現存最早之成熟文人七言古詩。 |
| **句數與篇幅** | 不限句數，篇幅長短完全由內容與情志需要決定。 |
| **平仄與對仗** | 不講究嚴格平仄（不分平仄），不必對仗；講究氣勢奔放流動。 |
| **用韻規則** | 用韻較寬，可依當時口語協韻，且**可以自由轉韻**。 |
| **文字總集** | 南朝梁昭明太子蕭統所編《昭明文選》，「事出於沉思，義歸乎翰藻」，收錄大量兩漢魏晉南北朝之古詩佳作。 |

## 三、流變與發展歷程
1. **魏晉建安風骨**：
   - 曹操、曹丕、曹植與建安七子，以剛健遒勁、慨當以慷的筆力抒發建功立業之志與民生離亂，形成著名「建安風骨（漢魏風骨）」。
2. **西晉詠史與太康文風**：
   - 西晉門閥士族掌權，文風多流於綺靡鋪張；[[左思]]以質樸剛健、慷慨激昂之筆，結合歷史典故與個人寒門苦悶，開拓文人詠史言志的新紀元。
3. **南北朝浮靡與唐代復古**：
   - 南朝齊梁宮體詩綺麗浮豔；初唐陳子昂首倡「直承漢魏風骨」，反對六朝齊梁纖巧之風。
   - 盛唐李白高舉古風大旗，以散行健句、大開大闔的仙才奔放揮灑，使古體詩抵達藝術巔峰。
